# Delhi Metro Operations & Passenger Analysis

## About the Project

Analyzed 7,000+ synthetic Delhi Metro records using MySQL to identify passenger demand,
station traffic, revenue, payment performance, and service delays. I Applied JOINs, CTEs,
subqueries, aggregations, and window functions to derive actionable insights and answer
real-world business questions.


## What I Analyzed

* Total trips and revenue
* Most used metro stations
* Peak and off-peak travel
* Passenger types
* Monthly revenue
* Payment status
* Station traffic
* Metro delays
* Repeat passengers

## SQL Skills Used

* SELECT, WHERE, ORDER BY
* GROUP BY and HAVING
* JOINs
* CASE statements
* Subqueries
* CTEs
* Window functions
* DENSE_RANK()
* Running totals
* Data quality checks

## Database Tables

The project contains 7 tables:

* stations.csv
* passengers.csv
* service_calendar.csv
* trips.csv
* payments.csv
* station_usage.csv
* delays.csv
